# Coding Standards — Backend Module

**Maintained by:** Member 1 — Backend, Database & APIs

This document defines the commenting and code style rules
followed throughout `contracts/` and `legaltech_project/`.
Any future code added to this backend should follow these
same rules for consistency.

---

## 1. Every `.py` file starts with a module docstring

```python
"""
filename.py
===========
One-sentence summary of what this file does.

Longer explanation if needed: what calls this file,
what it depends on, and any non-obvious context a
new developer needs before reading further.
"""
