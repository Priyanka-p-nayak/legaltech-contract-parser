# legaltech-contract-parser


This project is an Automated Contract Parsing and Risk Extraction System.

Features:
- PDF Upload
- Text Extraction using PyMuPDF
- Entity Extraction using spaCy NLP
- Risk Clause Detection
- PostgreSQL Database
- Django REST APIs
- Admin Dashboard

Tech Stack:
- Python
- Django
- Django REST Framework
- PostgreSQL
- PyMuPDF
- spaCy
